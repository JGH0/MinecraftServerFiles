A small community survival server with a technical twist: Carpet, controlled duping, update suppression — and still chill to play on. The world seed is public, and using the seed / a map for navigation is explicitly allowed.

How to join

Get the game ready

  • Minecraft Java 1.21.1
  • Install NeoForge 1.21.1 (from neoforged.net)
  • Create a NeoForge profile & launch once

Install the mods

  • Download mods.zip from the downloads page — the exact set the server runs
  • Drop the jars into your mods/ folder
  • Optional extras: minimap, fullbright, free cam — allowed!

Connect

  • Multiplayer → Add server
  • Address: mc.hallenbarter.org
  • Voice chat: connect on UDP 24454 (Simple Voice Chat)
  • That's it — say hi in chat 👋

First-time reading

  • Rules TL;DR: no griefing, no hacks — everything else is up for discussion.
  • Claim your builds with /chunkclaim.
  • Questions? Just ask in chat.
  • Server news & community: join the Discord.

Server rules & "cheats"

Allowed

  • Sand / gravity duping
  • TNT duping (for farms)
  • Update suppression & light suppression
  • Client-side QoL mods (minimap, fullbright, free cam)
  • Using the seed / world map for navigation
  • Cave x-ray / free cam (navigation only)
  • Lag machines for technical builds (e.g. update suppressors)

Not allowed

  • Griefing / large-scale destruction
  • Lava casting to bypass claim plots — and keep lava casts away from other builds in general (they're ugly and a pain to clean up)
  • Abusing /claim to trap someone (nobody can mine in a claimed chunk, so don't claim around players to box them in)
  • Fly hacks / movement cheats from client mods (elytra & legit flight is fine)
  • PvP advantage mods (auto totem, reach, knockback)
  • Ore x-ray (cave x-ray / free cam is fine)
  • Lag machines built to harm server performance
PvP & trapping are allowed — no hard feelings afterwards.

How the server stays sane

  • BetterGuard anticheat — normal profile, staff alerts, whitelist for legit client mods (Xaero, JEI, …)
  • Player Blocker — protects players (and their pets) from /player-style interference
  • Chunk Claim — claim land so your builds survive the night
  • Anti-Xray — ore textures are obfuscated server-side
  • Carpet (NeoForged) + scarpet scripts for name protection
  • Runs in Docker (itzg image) with 6 GB RAM, RCON internal only, auto restart 01:55 with in-game countdown
  • BlueMap — live 3D map of all three dimensions (open it)
  • Periodic world snapshots off the live volume — ask an admin if you want a copy

PvP, loot & content rules

  • PvP needs no consent — you may attack other players even if they haven't agreed. It's part of the server; just keep it in-game.
  • No raiding — killing, trapping & ambushing players is fair game, but breaking into bases and looting chests is not allowed.
  • Homes aren't safe zones — building traps inside bases and attacking players in their own home is allowed too; only taking their stuff isn't.
  • Loot is yours — after a kill you are never obligated to return the victim's dropped items. Giving stuff back is always your own choice, and it's exactly how you build your reputation here.
  • Recording & streaming is allowed under all circumstances — no need to ask, no exceptions. Streamers and YouTubers are welcome.
