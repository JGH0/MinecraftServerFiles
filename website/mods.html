The modpack

NeoForge 1.21.1 · maintained in the GitHub repo · same set on server & client

The server runs 35 jar files (34 unique mods) on NeoForge 1.21.1. Some are server-side protection/tech (marked Server), the rest are regular gameplay mods you should have on the client too — grab mods.zip and drop it into your NeoForge mods/ folder. Type to filter the list:
