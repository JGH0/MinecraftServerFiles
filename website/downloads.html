modpack download & world copies on request

World copy — on request

Want a copy of the world? Full snapshots (overworld, nether, end, plus server state) are made regularly from the live server volume, but they are not offered as public downloads.

Just ask: request a copy on the Discord or in-game and an admin will sort one out for you. Copies are multi-gigabyte world files, so please don't ask for one on a metered connection.

Explore it in your browser first

You don't need the download for a look around — the live 3D map covers the overworld, nether and end and updates as the world changes.

How copies are made

A small script copies the live Docker volume out of the container. The source lives in the repo as scripts/mc-backup.sh — nothing is hidden.

Restoring a copy

Drop the world files into the mc-data Docker volume and restart the stack — the server picks the world straight up. Copies are made straight from that same volume, so a restore is 1:1.

# world lives in the "mc-data" volume # the server restarts daily at 01:55 docker compose restart minecraft
